# Анализ вариабельности цен на товары

## Описание проекта
Необходимо было оценить вариабельность (разброс) цен на товары и выявить особенности распределения данных.

## Задачи:
1. Загрузить данные и проверить их на пропуски.
2. Рассчитать статистические характеристики (среднее, медиана, стандартное отклонение, квартили).
3. Визуализировать данные (гистограмма, boxplot).
4. Сформулировать выводы о ценовой политике.

## Инструменты:
* Python (Pandas, Matplotlib)
* Jupyter Notebook

## Основные выводы:
* Цены на товары имеют достаточно высокий разброс (стандартное отклонение 7.66 при среднем 13.6).
* Распределение цен близко к равномерному, без сильных выбросов.
* Показатель `Value` имеет бимодальное распределение (два пика), что может говорить о наличии двух разных групп товаров.
